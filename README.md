# Netflix Data Analysis

## Project Overview

This project analyzes Netflix Movies and TV Shows using Python and Pandas.

The objective of this project is to perform data cleaning, exploratory data analysis, and visualization to identify useful patterns and trends in Netflix content.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Excel

## Dataset

The dataset contains information about Netflix Movies and TV Shows, including:

- Show ID
- Category
- Title
- Director
- Cast
- Country
- Release Date
- Rating
- Duration
- Genre
- Description

## Data Cleaning

The following steps were performed:

- Checked the dataset structure
- Checked duplicate records
- Removed duplicate records
- Checked missing values
- Visualized missing values using a heatmap
- Converted release dates into datetime format
- Extracted year information
- Prepared the data for analysis

## Exploratory Data Analysis

The project analyzes:

- Movies vs TV Shows
- Netflix content released by year
- Movies released in specific years
- Top countries producing Netflix content
- Directors with the highest number of titles
- Content ratings
- TV Shows by country
- Movie duration
- Drama Movies and Kids' TV Shows

## Data Visualization

Visualizations were created using Matplotlib and Seaborn to understand:

- Movies vs TV Shows
- Netflix content by year
- Top countries by number of titles
- Ratings distribution
- Movies vs TV Shows over time
- Missing-value patterns

## Key Insights

- The dataset contains both Movies and TV Shows.
- Netflix content can be analyzed across different years, countries, ratings, and categories.
- The analysis identifies countries contributing the highest number of Netflix titles.
- Director-level analysis identifies directors with multiple Netflix titles.
- Missing values were identified and examined during data cleaning.
- Movies and TV Shows were compared to understand Netflix's content distribution over time.

## Conclusion

This project demonstrates an exploratory data analysis workflow using Python and Pandas. The Netflix dataset was cleaned, analyzed, and visualized to identify trends and answer different questions related to Netflix Movies and TV Shows.
